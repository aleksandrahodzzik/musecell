# MuseCell — public demo

Replays of real live runs of MuseCell, an AI scientist built on Meta's models (Muse Spark, Muse Wonder, SAM 3.1, and Muse Spark Open on Baseten) that names a compound's mechanism of action from cell images before it knows the compound.

This Space runs in replay-only mode: no API key, nothing here spends credits. Code, evaluation and how to run it live: https://github.com/aleksandrahodzzik/musecell
